Robotics software developed in TwinCAT 3, specifically for a Beckhoff CX7080 PLC.

The PLC receives inputs from buttons mounted on the front of the control box.
Communication between the PLC and robot controller (Arduino UNO with an RS485 shield) is done with Modbus RTU over an RS485 network.
